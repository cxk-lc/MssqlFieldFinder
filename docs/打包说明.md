# 打包说明 — 库表字段内容检索器

本文说明如何把本项目打包成**可独立运行的可执行程序**，以及后续迭代时如何一键重新打包。

---

## 1. 产物

| 项 | 内容 |
| --- | --- |
| 产物目录 | `MssqlFieldFinder\`（= 程序名，**不带版本号与扩展名**） |
| 产物文件 | `MssqlFieldFinder\MssqlFieldFinder-v<版本号>.exe` |
| 形态 | 单文件（onefile），双击即可运行 |
| 体积 | 10,687,325 字节（约 10.2 MB） |
| 本次校验值 | v1.6.0 → SHA256 `b75a4e9b34f40acab8ef4375bd20b9dbc39015fcad676cf59c916b9964e79d8d` |
| 依赖 | 目标机器**无需安装 Python**；需要 `Microsoft ODBC Driver for SQL Server` |

> 校验值随代码变化，每次打包由 `bat\build.bat` 现场打印，请以当次输出为准。

**产物目录的取名规则**：目录名取自 `src\__init__.py` 的 `__app_name__`，
不含版本号与扩展名；文件名在这个基础上追加版本号。这样安排的好处是
**同一个目录可以累积多个版本的 exe**（v1.6.0、v1.6.1 …），便于回退比对；
目录名固定不变，脚本、快捷方式、文档里的路径也就不用跟着版本一起改。

改程序名或改版本号仍然只需改 `src\__init__.py` 一处：

```
src\__init__.py
    __app_name__ = "MssqlFieldFinder"     ← 决定 产物目录名 / 产物文件名前缀
    __version__  = "1.6.0"                ← 决定 产物文件名里的版本号
```

程序运行时的配置文件（`config.json`、`connections.json`）生成在 **exe 所在目录**，
也就是产物目录内，而不是开发时的项目目录。即：

```
D:\某个文件夹\
    MssqlFieldFinder\                    ← 随 exe 一起拷走这个目录
        MssqlFieldFinder-v1.6.0.exe      ← 程序
        config.json                      ← 运行后自动生成（只含改过的设置）
        connections.json                 ← 保存连接方案后生成
```

因此**换机器时把 exe 拷过去即可**；若要连配置一起搬，把同目录的两个 json 一并拷走。

## 2. 环境要求

### 2.1 构建机（执行打包的机器）

| 项 | 要求 | 说明 |
| --- | --- | --- |
| 操作系统 | Windows 10 / 11（x64） | PyInstaller 不支持交叉编译，Windows 产物必须在 Windows 上打 |
| Python | 3.9 ~ 3.13（推荐 3.13） | **必须包含 tkinter**：安装时勾选 `tcl/tk and IDLE` |
| `pyodbc` | 已安装 | 运行期依赖，会被打进产物 |
| `PyInstaller` | ≥ 6.0（本次实测 6.22.3） | 缺失时 `bat\build.bat` 会自动安装 |
| 磁盘空间 | ≥ 500 MB 空闲 | 中间产物 `build\` 会占几百 MB |

本项目当前使用的开发环境（已就绪，可直接打包）：

```
C:\Users\admin\.workbuddy\binaries\python\envs\mssql_scanner\Scripts\python.exe
```

> 该环境由**系统 Python** 建 venv 得到（继承 tkinter），再安装了 pyodbc 与 PyInstaller。
> 托管 Python 不含 tkinter，不能用于打包。

### 2.2 目标机（运行 exe 的机器）

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11（x64），与构建机位数一致 |
| Python | **不需要** |
| ODBC 驱动 | **需要**：`Microsoft ODBC Driver for SQL Server`（17 / 18 或 SQL Server Native Client） |
| 网络 | 能访问目标 SQL Server 实例 |

驱动缺失时程序不会崩溃：打开「配置方案 → 新增 / 编辑」，ODBC 配置项下方会显示红色下载链接。

## 3. 一键打包（推荐）

**双击 `bat\build.bat`** 即可。脚本会自动完成：

1. 探测本机可用的 Python 解释器（要求同时具备 `tkinter` + `pyodbc`）；
2. 若缺 `PyInstaller`，自动安装到该解释器（仅首次，会打印安装到哪个环境）；
3. 从 `src\__init__.py` 读取**程序名**与**版本号**（唯一来源，无需手工同步）；
4. 按 `MssqlFieldFinder.spec` 执行打包，产物落到同名目录；
5. 打印产物目录、文件名、字节数与 **SHA256** 校验值。

预期输出（节选）：

```
============================================================
  打包：库表字段内容检索器
------------------------------------------------------------
  解释器   : C:\Users\admin\.workbuddy\binaries\python\envs\mssql_scanner\Scripts\python.exe
  程序名   : MssqlFieldFinder
  版本号   : 1.6.0
  产物目录 : MssqlFieldFinder\
  产物文件 : MssqlFieldFinder\MssqlFieldFinder-v1.6.0.exe
============================================================
...
============================================================
  打包完成
  产物目录 : D:\Documents\WorkBuddy\2026-10-09-13-54-26\MssqlFieldFinder
  产物文件 : MssqlFieldFinder-v1.6.0.exe
  大小     : 10687325 字节
   SHA256   : b75a4e9b34f40acab8ef4375bd20b9dbc39015fcad676cf59c916b9964e79d8d
------------------------------------------------------------
```

### 后续迭代的完整流程

```
1) 改代码
2) 改版本号：编辑 src\__init__.py 里的 __version__ = "1.6.x"
3) 双击 bat\build.bat
4) 从 MssqlFieldFinder\ 取走新的 exe
```

第 2 步是可选的——不改版本号也能打包，只是产物文件名不变，容易与上一版混淆。

> 自动化/批处理场景可用 `bat\build.bat -y` 跳过结尾的 `pause`。

## 4. 手工打包（不用脚本时）

```bat
cd /d D:\Documents\WorkBuddy\2026-10-09-13-54-26

:: 首次准备环境（已就绪的环境可跳过）
python -m pip install pyodbc pyinstaller

:: 打包（程序名与版本号决定产物名，可省略，spec 内有兜底默认值）
set MFF_NAME=MssqlFieldFinder
set MFF_VERSION=1.6.0
python -m PyInstaller --noconfirm --clean ^
    --distpath MssqlFieldFinder --workpath build ^
    MssqlFieldFinder.spec
```

等价的最简命令（不传环境变量时，产物为 `dist\MssqlFieldFinder.exe`，
因为未指定 `--distpath`，PyInstaller 会用默认目录 `dist`）：

```bat
python -m PyInstaller --noconfirm --clean MssqlFieldFinder.spec
```

> 注意：**产物目录由 `--distpath` 指定**，`spec` 里管不到它。
> `bat\build.bat` 之所以能保证「目录名 = 程序名」，是因为它先从 `src\__init__.py`
> 读出程序名，再拼进 `--distpath`。

## 5. 构建参数改哪里

**所有构建参数集中在 `MssqlFieldFinder.spec`**，`bat\build.bat` 不重复定义任何参数，
只负责找解释器、读程序名与版本号、拼 `--distpath`、报结果，避免两处配置漂移。
常见修改：

| 想改什么 | 改哪里 |
| --- | --- |
| 产物目录名 / 产物文件名前缀 | `src\__init__.py` 的 `__app_name__`（脚本与 spec 都从它派生） |
| 产物文件名里的版本号 | `src\__init__.py` 的 `__version__` |
| 产物是否带版本号 | spec 里的 `EXE_NAME`（改成 `BASENAME` 即不带版本号） |
| 排掉某些库以减小体积 | spec 里的 `EXCLUDES` 列表 |
| 需要额外的包 | spec 里的 `hiddenimports` 列表 |
| 附带图标 | spec 的 `EXE(...)` 加 `icon=r"路径\app.ico"` |
| 改成「绿色目录版」（启动更快） | 见 spec 文件末尾的注释说明 |

### 为什么是单文件（onefile）

单文件便于分发；代价是每次启动需先把内容解包到临时目录，首次启动约 1~3 秒。
若更在意启动速度，按 spec 末尾注释改成 `COLLECT` 形式，产物会是一个文件夹
（`MssqlFieldFinder\MssqlFieldFinder-v1.6.0\`，内含 exe 与依赖 DLL）。

## 6. 打包后自检

```bat
:: 在 cmd 中执行，打印版本、配置目录、驱动与已存方案
MssqlFieldFinder\MssqlFieldFinder-v1.6.0.exe --check

:: 只取版本号
MssqlFieldFinder\MssqlFieldFinder-v1.6.0.exe --version
```

窗口程序默认没有控制台，因此这两个命令会**附着到调用方的 cmd 控制台**；
若从资源管理器直接运行，则结果会写到 exe 同级的 `selfcheck.log`。

`--check` 的典型输出：

```
程序名          : MssqlFieldFinder
版本            : 1.6.0
是否打包运行    : True

设置文件        : ...\MssqlFieldFinder\config.json（存在：False）
方案文件        : ...\MssqlFieldFinder\connections.json（存在：False）

ODBC 驱动       : ODBC Driver 17 for SQL Server、SQL Server、...

```

## 7. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 双击 exe 无反应 | 多半是目标机缺 ODBC 驱动导致连接失败，程序本身仍会启动。先运行 `--check`，结果见 `selfcheck.log` |
| 启动要等一两秒 | 单文件版的正常现象（解包到临时目录）。改用 spec 里说明的目录版可消除 |
| 提示缺 `VCRUNTIME140.dll` | 目标机缺 VC++ 运行库，安装 [Microsoft Visual C++ Redistributable](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist) |
| 杀毒软件误报 | PyInstaller 单文件包的常见误报，加白名单或改用目录版 |
| `bat\build.bat` 报「未找到可用的 Python 解释器」 | 先运行「bat\诊断环境.bat」看哪台解释器同时具备 tkinter 与 pyodbc |
| 打包报 `script '...\main.py' not found` | spec 里 `SPECPATH` 解析异常，确认项目结构与 spec 同级（本仓库已做两种语义兼容） |
| exe 体积偏大（约 10 MB） | Python 运行时 + Tcl/Tk + pyodbc 的固有开销；已通过 `EXCLUDES` 排除 numpy/pandas 等 |
| 手工打包时产物落到了 `dist\` | 没传 `--distpath`。产物目录由该参数决定，spec 管不到；照第 4 节命令加上即可 |

## 8. 参数与依赖速查

**运行期依赖（会打进产物）**

| 包 | 版本 | 用途 |
| --- | --- | --- |
| Python | 3.13.12 | 运行时 |
| tkinter / tcl-tk | 随 Python 提供 | 图形界面 |
| pyodbc | 随环境安装 | SQL Server 连接 |

完整清单与版本约束见 **`requirements.txt`**（运行期）与 **`requirements-build.txt`**（构建期）：

```bat
python -m pip install -r requirements.txt          :: 只跑源码时需要
python -m pip install -r requirements-build.txt    :: 还要打包 exe 时需要（含上面这份）
```

**构建期依赖（不进产物）**

| 包 | 版本 | 用途 |
| --- | --- | --- |
| PyInstaller | 6.22.3 | 打包 |
| pyinstaller-hooks-contrib | 2026.8 | 第三方库钩子 |
| setuptools / packaging / pefile / altgraph / pywin32-ctypes | 自动安装 | PyInstaller 依赖 |

**关键命令**

```bat
:: 一键打包
bat\build.bat

:: 从源码运行（开发调试）
bat\run.bat

:: 环境诊断
bat\诊断环境.bat

:: 打包后自检
MssqlFieldFinder\MssqlFieldFinder-v<版本>.exe --check
```
