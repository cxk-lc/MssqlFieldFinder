# ------------------------------------------------------------------------------
# pyodbc —— SQL Server 连接，本项目唯一的第三方运行期依赖
#
# 依据：项目里只有两处 import pyodbc，且都在函数内惰性导入：
#         src/drivers.py   list_available()      枚举本机 ODBC 驱动（包了 try/except）
#         src/engine.py    build_connection_factory()  建立实际连接
#       惰性导入是刻意为之：实测把 pyodbc 完全屏蔽后，280 项纯逻辑单元测试
#       仍全部通过——即没装驱动的机器也能开发与验证逻辑层。
#
# 下限 >=5.2.0
#   pyodbc 是 C 扩展，必须靠与 Python 版本匹配的预编译 wheel 安装。
#   CPython 3.13 的 wheel 从 5.2.0 开始提供（本项目开发环境为 3.13.12）；
#   低于此版本在 3.13 上会退化为源码编译，通常因缺少 MSVC 工具链而安装失败。
#
# 上限 <6
#   pyodbc 5.x 的 API（connect / drivers / Error / cursor.timeout）多年稳定，
#   本项目按 5.x 编写。加个上限是为了防止将来 6.x 出现不兼容改动时，
#   无人值守的 pip install -r 把运行环境直接升坏；要试用新版可手工放宽。
# ------------------------------------------------------------------------------
pyodbc>=5.2.0,<6
